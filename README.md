## ChatGPT Plus 充值的具体操作步骤

### 第一步：打开订阅页面并选择 ChatGPT

通过本文的推广入口进入 BeWild 后，进入订阅区域，选择 ChatGPT 产品。

### 第二步：选择订阅时长

通常会看到单次订阅和长期订阅两类选项。

单次订阅适合短期使用，到期后不继续购买。长期订阅则适合确定要连续使用的人，但需要重点确认是否涉及自动续费或多月预存。

如果你只是第一次尝试，建议先选择一个月。先确认账号状态、网络环境和使用需求，再考虑多月方案。

### 第三步：登录自己的 ChatGPT 账号

页面会引导你打开 ChatGPT 并登录。

这里不要登录错账号。很多订阅问题不是付款失败，而是用户浏览器里同时登录了多个账号，最后把 Plus 开到了另一个邮箱。

建议操作前先确认：

- 左下角显示的账号邮箱；
- 当前浏览器是否登录了多个 ChatGPT 账号；
- 手机端和电脑端是否使用了不同账号；
- 你要升级的账号是否已经可以正常进入 ChatGPT。

### 第四步：提交页面要求的验证信息

根据套餐不同，平台可能要求提交账号 Session 信息，或者进一步提交 Cookie。

ChatGPT Plus 教程中说明，需要在已经登录 ChatGPT 的同一浏览器中打开指定页面，复制系统返回的完整内容，再粘贴回 BeWild。Pro 5x 教程还涉及额外的 Cookie 提交步骤。

这个步骤最容易出错，常见原因包括：

- 浏览器实际上没有登录 ChatGPT；
- 复制到的是空白内容；
- JSON 开头或结尾被截断；
- Session 和 Cookie 粘贴到了错误输入框；
- 中途切换了浏览器；
- 登录账号和提交信息不属于同一个账号。

如果页面提示信息为空、格式不完整或验证失败，不要连续重复付款。先返回检查登录状态和提交内容。

### 第五步：核对邮箱后付款

系统识别出账号邮箱后，先确认这是不是目标账号。

BeWild 帮助中心特别提醒，账号选错后，已经生效的订阅通常不能因为个人误操作直接退款或转移。

确认无误后，再进入收银台付款。平台教程显示，支付页面可能显示港币等换算后的金额，这不一定代表套餐发生了变化，最终应以收银台的应付金额和订单记录为准。

### 第六步：等待订单处理完成

付款后不要立刻关闭所有页面，也不要再次下单。

可以进入 BeWild 的订单记录查看状态。正常情况下，订单可能先显示处理中，完成后才变为已完成。帮助中心建议等待 5 至 15 分钟；Pro 方案或高峰时段可能需要更久。
